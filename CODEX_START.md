# Prompt inicial para o Codex

Use o conteúdo abaixo na raiz de um repositório novo junto com os demais arquivos deste pacote.

---

Você será o engenheiro principal do projeto Trading Bot Dashboard v0.1.

Antes de alterar qualquer arquivo:

1. Leia integralmente `PRODUCT.md`, `ARCHITECTURE.md`, `MILESTONES.md` e `IMPLEMENT.md`.
2. Inspecione o ambiente disponível, incluindo Flutter, Dart, Python, Docker e PostgreSQL.
3. Não instale nem configure credenciais de corretora ou OpenAI nesta etapa.
4. Crie um plano apenas para o marco M0 — Fundação.
5. Liste decisões que realmente bloqueiam a implementação. Use os padrões definidos nos documentos para o restante.

Depois, implemente somente o M0.

Requisitos de execução:

- mantenha backend e aplicativo executáveis;
- adicione testes e linters mínimos desde o início;
- crie `docs/STATUS.md`, `docs/DECISIONS.md`, `docs/RUNBOOK.md`, `docs/SECURITY.md` e `docs/DEMO.md`;
- registre comandos e resultados de validação;
- corrija falhas antes de declarar o marco concluído;
- preserve as fronteiras entre estratégia, risco e execução, mesmo que o backend comece como monólito modular;
- não avance para M1 sem revisão do usuário.

Ao terminar, entregue:

1. resumo do que foi criado;
2. comandos para executar;
3. testes e validações realizados;
4. problemas encontrados;
5. decisões pendentes;
6. demonstração objetiva do critério de aceite do M0.
